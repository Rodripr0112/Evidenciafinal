S

Ley de Senos

Relaciona lados y ángulos opuestos entre sí

asen A
=
bsen B
=
csen C

También expresada como: sen A / a = sen B / b = sen C / c

¿Qué significa?

En cualquier triángulo, el cociente entre un lado y el seno del ángulo opuesto a ese lado es constante. Esto permite calcular lados o ángulos desconocidos siempre que se conozcan al menos un par (lado + ángulo opuesto).

¿Cuándo se usa?

  • ASA Dos ángulos y el lado comprendido entre ellos
  • AAS Dos ángulos y un lado no comprendido
  • SSA Dos lados y un ángulo no comprendido (caso ambiguo)

Ejemplo resuelto (ASA)

Datos: A = 45°, B = 60°, c = 10

1

Calcular el ángulo faltante:

C = 180° − 45° − 60° = 75°

2

Aplicar la Ley de Senos:

a / sen 45° = 10 / sen 75°

a = 10 × sen 45° / sen 75° ≈ 7.3205

3

b = 10 × sen 60° / sen 75° ≈ 8.9658

Caso ambiguo (SSA)

Dados dos lados a, b y el ángulo A (opuesto a a), se calcula h = b · sen A.

  • a < h → Sin solución
  • a = h → 1 solución (triángulo rectángulo)
  • h < a < b → 2 soluciones
  • a ≥ b → 1 solución
C

Ley de Cosenos

Generalización del Teorema de Pitágoras para cualquier triángulo

a² = b² + c² − 2bc · cos A

b² = a² + c² − 2ac · cos B

c² = a² + b² − 2ab · cos C

Despejando el ángulo: cos A = (b² + c² − a²) / 2bc

¿Qué significa?

La Ley de Cosenos relaciona los tres lados de un triángulo con uno de sus ángulos. Cuando el ángulo es 90°, cos 90° = 0 y la fórmula se reduce al Teorema de Pitágoras (c² = a² + b²).

¿Cuándo se usa?

  • SSS Los tres lados son conocidos → encontrar los ángulos
  • SAS Dos lados y el ángulo comprendido → encontrar el tercer lado

Conexión con Pitágoras

Si C = 90°:

c² = a² + b² − 2ab · cos 90°

c² = a² + b² − 2ab · 0

c² = a² + b² ✓

Ejemplo resuelto (SAS)

Datos: a = 5, b = 7, C = 60°

1

Calcular el lado desconocido c:

c² = 5² + 7² − 2(5)(7) · cos 60°

c² = 25 + 49 − 70 · 0.5 = 39

c = √39 ≈ 6.245

2

Calcular el ángulo A:

cos A = (b² + c² − a²) / 2bc

cos A = (49 + 39 − 25) / (2·7·6.245)

A = arccos(0.7352) ≈ 42.64°

3

B = 180° − 60° − 42.64° ≈ 77.36°

Ejemplo resuelto (SSS)

Datos: a = 3, b = 4, c = 5

1

cos C = (9 + 16 − 25) / (2·3·4) = 0/24 = 0

C = arccos(0) = 90°

2

A = arccos((16+25−9)/40) ≈ 36.87°

B = 180° − 90° − 36.87° ≈ 53.13°
